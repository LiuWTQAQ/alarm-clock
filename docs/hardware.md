# 硬件接线表（Hardware Wiring）

> 本文件是**接线的唯一出处**。改线先改这里，再改代码里的 `firmware/include/pins.h`。
> 适用版本：ESP32-S3 DevKitC-1（N16R8）+ 2.4" ILI9341 + MAX98357A + VS1838B + 5 V 继电器。

---

## 1. 系统供电拓扑

```
        ┌──────────────┐        ┌─────────────────────────────┐
 DC 5V ─┤ 5.5×2.1 母座 ├─ 开关 ─┤ 2 A 保险丝 ─┬─ ESP32-S3 5V   │
 (3 A)  └──────────────┘        │             ├─ TFT VCC 3.3V  │
                                │             ├─ MAX98357A VIN │
                                │             └─ 继电器 VCC    │
                                │                             │
 DC 12V ┤ 5.5×2.1 母座 ├─ 开关 ─┤ 1 A 保险丝 ── 继电器 COM     │
 (1 A)  └──────────────┘        └─────────────────────────────┘
                                         │
                                    继电器 NO ── 12 V LED 灯
```

**三条硬规则：**

1. **5 V 与 12 V 两条独立回路**，只在一点共地（星型接地），共地点选在 5 V 输入的 GND 端子。
2. **5 V 不要给灯供电**，12 V 不要进逻辑电路。
3. 两个圆口座**中心正极**，上电前用万用表确认极性（见 §9）。

## 2. 引脚总表（唯一事实）

| GPIO | 功能 | 方向 | 备注 |
|---|---|---|---|
| 1 | 顶部按键 | 输入（内部上拉） | 按下接 GND |
| 2 | 红外接收 VS1838B OUT | 输入 | 3.3 V 供电 |
| 4 | I2S BCLK | 输出 | MAX98357A BCLK |
| 5 | I2S LRC | 输出 | MAX98357A LRC |
| 6 | I2S DIN | 输出 | MAX98357A DIN |
| 7 | TFT 背光 | 输出 / PWM | 经 S8050，或直连 3.3 V（见 §4） |
| 8 | TFT DC | 输出 | — |
| 9 | TFT RST | 输出 | — |
| 10 | TFT CS | 输出 | — |
| 11 | TFT MOSI | 输出 | — |
| 12 | TFT SCK | 输出 | 40 MHz |
| 13 | TFT MISO | 输入 | 可不接 |
| 14 | 继电器 IN | 输出 | **高电平吸合** |
| 15 | 蜂鸣器（可选） | 输出 | 经 S8050 |
| 21 | 红外发射 | 输出 | 经 S8050，38 kHz 载波 |

**保留 / 禁用：**

| GPIO | 原因 |
|---|---|
| 26–32 | SPI Flash |
| 33–37 | Octal PSRAM（N16R8） |
| 0、3、45、46 | Strapping，上电电平影响启动 |
| 19、20 | USB D−/D+ |
| 43、44 | UART0（串口日志） |
| 16、17 | **预留**（触摸 T_CS / T_IRQ 备选） |

## 3. 显示：ILI9341（SPI）

| 模块丝印 | 接到 | 线色建议 |
|---|---|---|
| VCC / 3V3 | 3.3 V | 红 |
| GND | GND | 黑 |
| CS | GPIO10 | 橙 |
| RESET / RST | GPIO9 | 黄 |
| DC / RS | GPIO8 | 绿 |
| MOSI / SDI | GPIO11 | 蓝 |
| SCK / CLK | GPIO12 | 白 |
| MISO / SDO | GPIO13（可省） | 灰 |
| LED / BL | 3.3 V（或 GPIO7，见 §4） | 紫 |

**触摸引脚（T_CLK / T_CS / T_DIN / T_DO / T_IRQ）本轮全部留空。**
早期草稿曾把 `T_CS` 定在 GPIO14、`T_IRQ` 定在 GPIO21，这两个脚现在被继电器和红外占用；将来加触摸改用 **GPIO16 / GPIO17**。

## 4. 背光的两种接法

| 方案 | 接法 | 适用 |
|---|---|---|
| A（默认） | `LED` → 3.3 V | 常亮，最简单，P1 阶段用 |
| B | `GPIO7` → 1 kΩ → S8050 基极；S8050 发射极 GND、集电极接 `LED`；`LED` 另经 100 Ω 接 3.3 V | 需要调光 / 夜里自动变暗 |

选 B 时，`pins.h` 里保留 `PIN_TFT_BL 7`，代码用 `ledcSetup/ledcWrite`；选 A 时该引脚悬空即可，代码里 `digitalWrite(7, HIGH)` 也无害。

## 5. 按键

| 按键引脚 | 接到 |
|---|---|
| 一端 | GPIO1 |
| 另一端 | GND |

- 使用**内部上拉**，不按为高、按下为低。
- 若线长 > 20 cm，在 GPIO1 与 GND 之间并 **100 nF** 电容做硬件消抖。
- 若内部上拉不够稳（读数抖动），加 **10 kΩ** 外部上拉到 3.3 V。

## 6. 音频：MAX98357A（I2S）

| MAX98357A | 接到 | 说明 |
|---|---|---|
| VIN | 5 V | 峰值电流约 1 A，别接 3.3 V |
| GND | GND | 与主控共地 |
| BCLK | GPIO4 | 位时钟 |
| LRC | GPIO5 | 左右声道时钟 |
| DIN | GPIO6 | 数据 |
| SD | 3.3 V | 拉高使能；悬空可能静音 |
| GAIN | 悬空 | 默认 9 dB；接 GND 为 15 dB，接 VDD 为 12 dB |
| OUT+ / OUT− | 喇叭 4 Ω 3 W | 不分正负，但两路都不要接地 |

- 喇叭线用 **0.5 mm² 以上**，长度 < 30 cm。
- VIN 与 GND 之间就近并 **100 µF 电解 + 100 nF 瓷片**，否则大音量时会复位。
- 功放与继电器的地都回到 5 V 输入的 GND 端子，不要串在 TFT 的地线上。

## 7. 红外

### 7.1 接收 VS1838B

| VS1838B | 接到 |
|---|---|
| VCC | 3.3 V（串 100 Ω） |
| GND | GND |
| OUT | GPIO2 |

- VCC 与 GND 之间就近并 **100 nF**；VS1838B 对电源纹波极敏感，纹波大时解码会随机失败。
- 接收头正面朝向房间，别被外壳挡住；避开屏幕背光直射。

### 7.2 发射（940 nm）

```
        5V
         │
       [33Ω]
         │
       ──▶|──  940 nm 红外 LED
         │
         C
GPIO21 ─[1kΩ]─ B   S8050 (NPN)
         E
         │
        GND
```

| 元件 | 参数 | 说明 |
|---|---|---|
| R_base | 1 kΩ | 限制基极电流 |
| R_led | 33 Ω / 0.25 W | 5 V 供电时约 100 mA 脉冲 |
| 三极管 | S8050 / 2N2222 | 不能用 GPIO 直驱 LED |

> 若改用 3.3 V 供电，`R_led` 换成 **18 Ω**，射程会短一些。

## 8. 继电器与 12 V 灯

| 继电器模块 | 接到 |
|---|---|
| VCC | 5 V |
| GND | GND（与主控共地） |
| IN | GPIO14 |
| COM | 12 V + |
| NO | 灯座中心触点 |
| NC | 不接 |
| 灯座外壳 | 12 V − |

要点：

- **高电平触发**：`digitalWrite(14, HIGH)` 吸合，`LOW` 释放。代码里注意上电初始化先写 `LOW`。
- 上电瞬间若继电器"哒"一下误吸合，在 `IN` 与 `GND` 之间加 **10 kΩ 下拉**。
- 模块自带光耦与续流二极管；若自制驱动电路，线圈两端必须并 **1N4007**（负极接 5 V）。
- 12 V 回路串 **1 A 保险丝**；灯座接线处用热缩管包住。
- 触点侧与逻辑侧**不要共地**（模块已隔离，别自己用一根线把两边连起来）。

## 9. 上电前检查（每次改线都做）

```text
□ 万用表通断档：VCC 与 GND 之间不响（响 = 短路）
□ 圆口座中心为正极（红表笔中心、黑表笔外壳，读数应为 +5 V / +12 V）
□ CS / DC / RST 三根没有互换
□ 继电器 IN 与 GND 之间 10 kΩ 下拉已装
□ 12 V 与 5 V 没有交叉
□ 所有 GND 最终汇聚到同一点
```

**首次上电顺序：**

1. 只接 5 V，不接 12 V、不接负载 → 量 3.3 V 是否稳定；
2. 烧录屏幕自检程序 → 屏幕正常显示；
3. 接 12 V，空载测继电器吸合/释放；
4. 最后接灯。

## 10. 电流预算

| 负载 | 典型 | 峰值 |
|---|---|---|
| ESP32-S3（Wi-Fi 开启） | 80 mA | 350 mA |
| TFT（含背光） | 60 mA | 80 mA |
| MAX98357A + 喇叭 | 60 mA | 1000 mA |
| 继电器线圈 | 70 mA | 70 mA |
| 红外发射（占空比 < 5%） | — | 100 mA |
| VS1838B | 1 mA | 2 mA |
| **5 V 合计** | **≈ 270 mA** | **≈ 1.6 A** |
| 12 V LED 灯（3 W） | 250 mA | 250 mA |

→ **5 V / 3 A** 余量约 2 倍，**12 V / 1 A** 余量 4 倍，符合要求。

## 11. 线色与装配约定

| 颜色 | 用途 |
|---|---|
| 红 | 5 V |
| 黑 | GND |
| 黄 | 12 V |
| 橙 | 片选 / 使能类信号 |
| 蓝、绿、白 | SPI / I2S 信号 |
| 紫 | 背光 |

- 杜邦线母对母直插，**线长 ≤ 15 cm**，SCK 最短；
- 超过 3 根线的束用扎带固定，避免拽动时拉脱；
- 洞洞板阶段：电源与地走 1 mm 以上铜箔或双股并线，信号线细一些无妨。

## 12. 常见接线故障对照

| 现象 | 检查点 |
|---|---|
| 屏幕白屏 | CS(10) / DC(8) / RST(9) 是否接反或虚接 |
| 屏幕全黑但串口正常 | LED 背光是否接 3.3 V |
| 屏幕花屏 | SCK 线过长，或 SPI 降到 20 MHz |
| 继电器上电误吸合 | IN 缺下拉，或初始化顺序错误 |
| 喇叭有"沙沙"声 | 电源纹波，VIN 并 100 µF |
| 遥控距离只有 10 cm | 红外 LED 限流电阻过大 / 三极管未饱和 |
| 按键误触发 | 缺 100 nF 消抖，或线太长引入干扰 |
